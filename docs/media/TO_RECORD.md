# Media to record

Record in the Quest (Meta button → Camera → Record video). Keep each GIF under 8 MB, about 720 px wide.
Replace the placeholder with the same file name; the docs and the website pick it up automatically.

| File | Length | What to show |
|---|---|---|
| `hero.gif` | 5 s | Fire: lantern glow breathing, leaves falling |
| `cards.gif` | 5 s | Card scene: look across the glowing cards, pinch one, mist rises |
| `wood.gif` | 5 s | Wood: bamboo sways on the out-breath, ground ring spreads |
| `fire.gif` | 5 s | Fire: lantern, embers, maple leaves |
| `water.gif` | 5 s | Water: rain and rings on the pond |
| `leave.gif` | 4 s | Palms together, the white ring fills, back to the cards |
| `walkthrough.mp4` | 1–2 min | Choose a card → a scene → a few breaths (no placeholder; it appears on the website once the file exists) |
